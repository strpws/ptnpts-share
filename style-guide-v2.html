5 — Shape & Border Radius

Radii

  • 8px — card shell
  • 4px — chart row hover state
  • 2px — bar tracks, bar fills, legend swatches
  • 9999px — diff pills (full pill)

Bar Geometry

  • Track height: 13px
  • Scale max: set ~7% above highest data point
  • Bar fills are proportional to max, not 100%
  • Bar tag column: fixed 24px
  • Bar value column: fixed 34px, right-aligned

7 — Design Rules

Color Assignment

  • Blue (#00559A) always = PTN (negeri)
  • Gold (#DBAA00) always = PTS (swasta)
  • Never swap these two roles
  • Use pale variants only for pill backgrounds
  • Use deep variants only for text on pale backgrounds

Typography Rules

  • Lora = editorial (titles, decks only)
  • PT Sans = UI / data (everything else)
  • All labels are Bold weight — no Regular for labels
  • Deck is the only italic usage

Card Layout

  • Width is fluid — fills the CMS column
  • Card background: white (#FFFFFF) — blends with article page
  • body background must be #FFFFFF in all production files — never #F0F2F5
  • No border, no box-shadow
  • Always include title, deck, legend, chart, and source note
  • Source must credit dataset and date
  • Footer always separated by a #DDD border

Accessibility

  • Chart is role="list"; each row role="listitem"
  • aria-label on each row: "{label}: PTN X%, PTS Y%"
  • Legend and pills marked aria-hidden="true"
  • Honor prefers-reduced-motion: disable all transitions

Data Formatting

  • Percentages: always 1 decimal place (e.g. 28.7%)
  • Diff pills: 1 decimal place + " pp" (percentage points)
  • Bar scale ceiling: max data value + ~7% headroom
  • Range labels use en-dash (–), not hyphen (-)

Hover Interaction

  • Row background → #F5F8FC on hover
  • PTN bar brightens to #0062B1
  • PTS bar brightens to #E8B500
  • Diff pill appears (opacity + scale)
  • cursor: default — this is not a link
